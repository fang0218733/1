# 知伴落地与管理说明

## 当前交付范围

原生微信客户界面 + 电脑网页后台 + Node.js 24服务端 + SQLite持久数据库。无第三方Node依赖。暂不收费，所有价格都是参考价格，没有收款码、商户密钥或支付回调。默认小程序仍使用本地演示；启用服务端后身份与订单才跨设备保存。

没有注册小程序、开通云资源、购买域名、完成备案或实际发布。真实微信身份与DeepSeek接口尚未实测；自动化测试使用替身服务，不代表外部服务已连通。

现有三张角色保留。你已有的新角色尚未导入，可以使用后台录入正文和上传封面。默认普通成品公开，但提交前客户必须确认告知；私人定制禁止公开。问卷、客户具体要求、身份标识从不作为大厅字段返回；最终公开内容必须由管理员人工检查、去除个人信息。

## 现在本机体验后台

需Node.js 24（使用内置SQLite），从仓库根目录运行：

```sh
DEMO_MODE=true node server/index.cjs
```

Windows PowerShell：

```powershell
$env:DEMO_MODE="true"
node server/index.cjs
```

在你自己的电脑浏览器访问 `http://127.0.0.1:8080/admin`，不填密码即可进入**仅本机演示**。该模式拒绝绑定公网地址，无真实登录或DeepSeek调用；不得对外部署。

在微信开发者工具联调本机服务时，可临时把 `miniprogram/data/runtime.js` 的 `apiBase` 设为 `http://127.0.0.1:8080`，仅开发工具中临时关闭合法域名校验。真机与正式发布必须使用HTTPS合法域名，不能使用这个本机地址。浏览器后台和小程序只有连接同一服务端时才共享数据；原本纯本地演示数据不迁移，避免样例混入真实订单。

后台：登录 → 角色大厅 → 新增角色 → 填名称、分类、标签、简介、正文 → 上传PNG/JPEG/WebP封面（2MB内）→ 勾选发布 → 保存。取消发布可下架，订单公开卡在原订单中重新审核。后台支持上传封面和粘贴文本，暂不支持批量导入任意角色卡文件格式。

订单：查看完整答案 → 生成草稿或手动制作 → 编辑最终卡 → 人工审核 → 确认交付；普通订单可同时发布，私人订单服务端强制禁止公开。AI草稿不会自动成为成品。审核冲突会要求刷新，避免覆盖其他操作。

## 正式接入步骤（需要你的官方账号）

1. 注册个人主体微信小程序，确认“虚构角色卡/定制生成”适用类目、AI生成内容要求与主体资格，完成适用的备案、隐私配置和审核。未确认资格前不能承诺上线。暂不接真实微信支付。
2. 预算未确定，不代购资源。本项目先使用可独立部署后端，适合小规模单管理员；可选择一台带持久磁盘的云服务器。不是已经开通的微信云开发。若选微信云开发，需将当前SQLite存储替换为云数据库并适配认证，不可将SQLite直接放进无持久磁盘的云函数。
3. 配置自有域名和有效HTTPS证书，按部署地域完成适用备案。在微信后台配置请求合法域名，封面图片需配置下载合法域名；不要在正式版本关闭TLS或合法域名校验。
4. 服务器安装Node.js 24，上传仓库，安全注入环境变量。`server/.env.example`列出名称，**不能把真实值提交Git，也不要发到聊天里**。本机`.env`不是自动读取，使用部署平台密钥设置或Node `--env-file` / systemd `EnvironmentFile`。
5. 服务端必须设置：`DEMO_MODE=false`、`PUBLIC_ORIGIN=https://你的真实域名`（无尾斜线）、16位以上随机`ADMIN_PASSWORD`、`WECHAT_APP_ID`与`WECHAT_APP_SECRET`。数据目录`DATA_DIR`及`MEDIA_DIR`须位于持久磁盘，权限只开放给服务用户。端口仅允许反向代理访问；后台经HTTPS使用安全Cookie。错误和日志不输出密钥。
6. 需要生成时，通过DeepSeek官方账号配置`DEEPSEEK_API_KEY`。不设也能管理角色并手动制作。选择开通时确认费用；密钥只在服务器，不能放小程序。服务端出站需可访问 `api.weixin.qq.com` 与 `api.deepseek.com`，保持TLS验证。
7. 默认不自动消费AI额度。预算确认后设`AUTO_GENERATE=true`，新申请进入持久待处理队列，服务每2秒取一单生成，默认每天最多自动尝试20单（UTC日界），可用`MAX_AUTO_GENERATIONS_PER_DAY`设置1—100。手动“生成”不受该自动额度限制且会产生费用。失败保留诊断供后台重试；中断生成2分钟后允许恢复。没有自动计费或费用预估功能。
8. 把小程序`runtime.js`的`apiBase`设为该HTTPS域名，保持无尾斜线。发布客户版本前先完成真实微信登录、两套餐申请、后台生成与审核、普通公开、私人不公开的全流程验收。

参考部署文件：`server/persona.service.example`（需创建服务用户并配置实际Node路径），`server/Caddyfile.example`（需安装Caddy并替换域名）。Docker可从根目录用 `docker build -f server/Dockerfile .` 构建；运行必须挂载持久卷到`/data`并通过平台注入上述变量。**不要在生产启用DEMO_MODE**。Docker和systemd模板尚未在真实服务器上部署验证。

## 数据、统计与维护

下载人数为经过身份识别的去重用户数，成功复制或保存文本后调用统计接口；同一人重复只计一次。收藏可取消，热度=下载人数×2+当前收藏数；初始统计为0，不伪造热度。云端是已登录用户ID维度，纯本地演示只统计本机，因此不能用演示数代表真实使用人数。重复请求/网络失败可能导致统计与实际文件行为不完全一致。

SQLite存储订单、身份会话、角色、收藏与下载；上传封面单独存目录。该版本适合单实例、小规模试运营，公开列表分页，但存储统计扫描与后台列表暂未针对大规模数据优化。不得横向部署多实例访问不同数据盘。每次部署保留持久目录；用SQLite一致性备份方式备份数据库，并同时备份封面目录。制定备份频率、保留周期、删除请求处理及恢复演练后再面向真实客户运营。管理员可在正式服务器按客户要求处理数据删除，当前尚无客户自助注销/删除界面。

制作时限、修改次数和退款规则仍未确定，当前没有对客户承诺、也没有退款按钮。AI模型名称与接口使用 `deepseek-chat`，接入时需按官方当时支持的模型核实。后台单管理员密码登录，无多管理员权限系统；忘记密码需在部署环境安全重设并重启服务，已有后台会话随重启失效。
