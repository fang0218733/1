# 角色大厅与付费下载

大厅按全部、免费、付费筛选。现有八张独立角色免费，陈砚下载价格为2元；管理员可为更多角色设置免费或付费及独立价格。

本地演示只展示付费卡简介，不能付款或解锁。线上仍使用人工核实接口，不包含微信支付、赞赏码或自动收费。客户提交下载申请后，在我的需求单核对编号并上传凭证；凭证不会改变付款状态。经过身份验证的管理员核对实际收款金额后记录收款，服务端授予该客户下载权限；记录全额退款会撤销权限。2元角色下载不计入定制邀请返款核对人数。

新数据库中陈砚只有公开简介。管理员在角色管理中打开陈砚，将原《陈砚_陪聊人设.txt》通过“上传角色TXT”录入，保留付费勾选和2元价格后保存。旧数据库已有陈砚正文时会保留在服务端。付费正文不可放入小程序源码、公开静态文件或公开仓库；上传、收款核实和上线需要先完成真实后台配置。历史免费版本或已导出的正文无法追回，付费保护仅约束新版本服务端下载。

验收：微信开发者工具编译，检查免费/付费、BG/GL/BL及性别筛选；后台录入陈砚；两个测试用户分别验证申请、凭证、管理员核实、本人下载、另一用户不能获取正文、退款撤权。代码检查与自动测试不替代开发者工具及真机验证。
