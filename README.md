# 知伴 · 原生微信人设定制

客户流程：免费大厅独立浏览 → 选择50题、100题或私人定制 → 全选择题答题（可跳过、自动保存）→ 汇总确认 → 待确认需求单 → 私聊核对报价与交付安排 → 管理员人工核实收款 → 人工制作 → 客户领取复制。

本版本不展示赞赏码、不跳转付款、不将套餐费称为自愿赞赏，也不调用AI自动制作。会员、邀请返款及超详细旧版方案不在当前销售入口。价格由配置和后台独立维护：50题12.8元、100题18.8元沿用此前约定；私人定制未设置，显示“价格待确认”。

## 开发者工具预览

导入包含`project.config.json`的仓库根目录，使用工具支持的游客/测试模式或本人真实AppID。默认`miniprogram/data/runtime.js`没有服务地址，只运行本地模拟；订单样例和收款状态不能代表真实付款、后台权限或跨设备同步。不要提交AppSecret、密码或私人开发者配置。

## 检查与后台体验

使用Node.js 24，无需安装第三方依赖：

```sh
npm run check
npm test
npm run server:demo
```

在你自己的电脑浏览器打开本机8080端口的`/admin`，可体验仅本机模拟后台。正式后台需HTTPS、服务端管理员登录和真实微信身份配置；客户端无法修改收款状态。

需求单保留唯一编号、题库版本与题目快照、全部答案、创建时间及提交时报价快照。后续约定报价独立记录，不覆盖原快照。付款状态和制作状态分别记录；只有管理员核实后可开始制作和交付。后台可录入约定交付时间、修改次数、退款条件，粘贴或上传TXT成品；私人定制禁止公开。

当前部署、人工收款与平台确认事项见 [人工需求单部署说明](docs/MANUAL_DEPLOYMENT.md)。历史架构和备份说明见 [原部署记录](docs/DEPLOYMENT.md)，旧AI/会员支付方案不能作为本版已启用能力。
