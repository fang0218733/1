# 微信小程序

原生微信小程序基础项目，使用 JavaScript、WXML、WXSS，无第三方依赖。

## 本地预览

1. 下载仓库，或使用 Git 克隆。
2. 在微信开发者工具中导入仓库根目录，类型选择小程序。
3. 将 project.config.json 的 appid 替换为自己的小程序 AppID；当前 touristappid 仅用于游客体验，若工具不支持请选择工具提供的测试号或填入正式 AppID。
4. 编译打开首页，点击按钮查看交互。

## 代码检查

安装 Node.js 22 后运行：

```sh
npm run check
```

检查验证 JavaScript 语法、JSON 格式和页面文件完整性。微信模拟器编译及真机预览仍需要微信开发者工具。

## Codex 配置

在 Codex 的云环境创建页选择 fang0218733/1，按页面提示完成仓库授权。环境使用 Node.js 22 或更新的受支持 LTS 版本。无需 npm install，检查命令为 npm run check。完成环境测试并发布后开始任务。

AGENTS.md 提供项目开发说明。小程序业务需求尚未确定，目前仅包含基础首页。

## 文件位置

- miniprogram/：小程序源代码
- project.config.json：开发者工具配置
- scripts/check.cjs：基础检查
- .github/workflows/check.yml：自动检查

不要将 AppSecret、令牌、密码写入仓库。私有开发者工具配置和本地环境变量已加入忽略规则。

## DeepSeek 陪聊人设定制 · 第一阶段

客户流程：套餐首页 → 50题完整版 / 100题精细版 → 自动保存答题 → 汇总与返回修改 → 确认提交本地演示订单 → 我的订单。多选题中的“由设计师决定”与具体偏好互斥，所有操作通过选项完成，无文本填写框。

- 套餐与参考价格统一配置在 `miniprogram/data/config.js`，当前价格仅为演示配置，不是正式报价，不发生支付。
- 中文题库位于 `miniprogram/data/questions.js`。精细版包含基础50题及额外50题，深入人物矛盾、情境反应和关系变化。
- `miniprogram/services/api.js` 是 Promise 服务适配接口（套餐、身份、订单），草稿为同步本地存储。当前不接入 DeepSeek、真实身份验证、后台或数据库。
- 本地键 `persona-demo-v1` 保存草稿与订单；清除缓存会丢失。预置“制作中”“已完成”样例，新提交记录保持“待处理”，不自动生成成品。
- 已提交答案保留快照，重复提交不会重复下单。从首页确认开启新定制后重新作答，原订单保留。

后续后台适配需实现服务端套餐版本/报价与答案校验、认证及订单归属检查、幂等提交、制作状态流转和成品访问控制。不要信任本地价格、身份或订单状态。正式支付、真实制作以及 DeepSeek API 凭证管理应作为独立阶段接入，凭证不得置于小程序客户端。

### 验证

```sh
npm run check
node scripts/test-flow.cjs
```

第二条命令在模拟微信存储和页面上下文中验证题数、题目/选项唯一性、草稿恢复、选项互斥、答案校验、提交去重及订单状态，不替代微信渲染与平台 API 验证。

微信开发者工具人工验收：

1. 导入仓库根目录，使用工具支持的测试 AppID / 游客模式编译，检查首页、长文字、多选按钮、小屏与大字体显示。
2. 分别选择两个套餐，逐题选择并返回修改；关闭再打开小程序，确认草稿位置与答案恢复。
3. 汇总页点击任意题修改；未答完不能提交，答完后检查确认弹窗及取消/确认分支。
4. 确认新订单标注演示、处于待处理；检查三种状态筛选、已完成样例人设卡和复制至剪贴板。
5. 从首页开启新的定制，检查原订单保留；在真机检查导航、自动存储、滚动和剪贴板授权/失败提示。
